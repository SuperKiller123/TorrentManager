Pin Torrent Manager

Windows lets you choose which applications are pinned. Complete the selected installation option with these steps.

Pin to taskbar

  1. Open Torrent Manager.
  2. Right-click its icon on the Windows taskbar.
  3. Select Pin to taskbar.

Pin to Start

  1. Open Windows Start and search for Torrent Manager.
  2. Right-click the application.
  3. Select Pin to Start.

The application is available in Start's app list after installation. Creating that shortcut alone does not pin it.
