# Torrent Manager v1.0

## Újdonságok

- Átrendezett kezdőlap: egyetlen torrentdarabszám, szöveges tárhelyadat, átviteli sebesség és a legutóbb letöltött torrentek nevei.
- Új Alkalmazás fül: áttekinthető frissítés, újratelepítés, eltávolítás és kiadási leírás görgethető oldal nélkül.
- Külön beállítás a minimalizáláskor és a bezáráskor értesítési területen futó alkalmazáshoz. A háttérben futó automatizálás az ablak elrejtésekor folytatódik.
- A tálcaikon menüjéből megnyitható mind a négy fül, és indítható vagy leállítható az automatizálás. Visszatéréskor a program maximalizált ablakban nyílik meg.
- F11 az első kötelező beállítás során is használható.
- A telepítő nem jeleníti meg az összefoglaló és a befejező oldalt. A Windows Gépházból indított eltávolítás nem kér még egy indítási megerősítést.

## English

The dashboard, Application page and notification area controls have been redesigned. First setup supports F11. Setup skips its summary and completion pages, and Windows Settings starts uninstall without a second confirmation.

The installer is unsigned, so a browser or Windows may still warn before running it. SHA-256 checksums verify download integrity but do not replace code signing.
